# zhzix.github.io

Personal academic site of Zixiao Zhang, built with the [Minimal Mistakes](https://github.com/mmistakes/minimal-mistakes) Jekyll theme.

- `index.md`: home page
- `_pages/`: Research, Publications and CV pages; one file per research topic in `_pages/research/`
- `_data/navigation.yml`: top navigation
- `_config.yml`: site title, sidebar and links
- `assets/images/`: figures
